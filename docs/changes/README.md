# Historial de cambios

Notas concisas por cambio sustancial, para que cualquier agente (o humano)
entienda el **qué**, el **porqué** y las **gotchas** sin releer todo el diff.
Un archivo por cambio, nombrado `YYYY-MM-DD-slug.md`.

Plantilla:

```md
# Título del cambio

**Qué**: una frase.
**Por qué**: motivación (petición, bug, rendimiento).
**Dónde**: archivos clave.
**Aprendido**: gotchas, edge cases, decisiones no obvias. (Opcional.)
```
