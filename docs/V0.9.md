# Zeroed 0.9

Resumen historico de v0.9. La fuente de verdad del estado actual es el codigo.

## Producto

FPS Zombies web en TypeScript estricto, Three.js, Vite y Vitest. El menu
publico entra en Zombies y selecciona `classic` o `burned-mansion`; el shell
comparte render, input, jugador, armas, balistica, audio, efectos, HUD, pausa y
perfiles de dispositivo. `ZombiesMode` posee la run y `ZombieArena` posee el
mapa.

## Gameplay

- Points solo pasan por `PlayerEconomy`: hit +10, baja +50, headshot +150 y
  cuchillo +200. Mystery Box cuesta 950 y las compras son atomicas.
- Range tiene reserva ilimitada; Zombies decide reserva finita por modo.
- Burned Mansion progresa de M1911 a AK-47/M4A1, bunker, wall buys, puertas,
  barreras, pickups y sala secreta. Tres lamparas activadas con USE reciben
  almas de bajas cercanas y abren una pared una vez por run.
- Ray Gun se garantiza a 115 bajas. ZEUS-77 es legendaria en la caja y encadena
  objetivos. Ambas usan `EnergyProjectiles`.
- El final de 30000 Points usa `PLAYING -> ENDING -> CREDITS -> FINISHED` y
  bloquea input, dano, compras, rondas, spawns, proyectiles y audio.

## Arquitectura y combate

- Las armas son `WeaponDefinition` + `Weapon`; las vistas Three.js consumen
  `pendingEvents`. La logica pura no importa Three.js.
- Balistica: gravedad/drag, subpasos de hasta 3 m, raycast segmentado y pools.
  Cabeza = 3x; splash y cadena no duplican feedback de headshot.
- Zombies normal/shiny/brute comparten IA y limite global 24. Walker es
  Quaternius; Shiny usa dorado y estrellas; Brutus es humanoide propio de
  2.30 m, lento, resistente y letal.
- Navegacion: steering local + A* por planta + anti-stuck. Puertas/barreras
  cambian topologia. La escalera del bunker es pendiente continua de canal
  unico. Pasos 3D usan ocho fuentes reutilizadas y fallback sintetizado.

## Plataforma

PWA: shell en precache, modelos/texturas/audio en runtime cache; navegador
actualiza al entrar y standalone espera a selector o pausa. Capacitor reutiliza
el build Vite y genera el APK debug en
`android/app/build/outputs/apk/debug/app-debug.apk`.

Assets: armas mayormente procedurales o Quaternius CC0; walker Quaternius
CC-BY 3.0; texturas Poly Haven CC0; audio local con fallback sintetizado.

## Rendimiento y validacion

Pools: balistica 32, agujeros 96, casquillos 24, chispas 16, humo 10, pasos 8
y drops 12. `DeviceProfile` limita calidad movil. Obligatorio:
`npm run typecheck` y `npm run test`; PWA, WebGL, DOM, audio y flujos completos
requieren validacion manual.
